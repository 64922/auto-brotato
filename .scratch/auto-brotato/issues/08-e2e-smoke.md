# 票据 08：端到端闭环冒烟（难度页 → 波次 → 商店 → 升级）

- Status: ready-for-agent
- Blocked by: 06, 07
- 关联：架构 §10、票据 04–07

## 背景

P1 完成标志：整条流程无需人工干预地跑通最小闭环，作为 P2/P3 的验证基础。

## 目标

1. 冒烟脚本/清单（可重复执行）：
   - 人工停在难度页 → agent 检测并提示 → 输入难度 → 自动开局；
   - 自动通过第 1–2 波（占位走位不死）；
   - 商店打开：自动执行"评估→离开"（或买最便宜一件）并成功进入下一波；
   - 触发升级页时自动选卡；
   - 到第 2 波结束（或主动 stop）→ 战报 + 回放文件完整。
2. 记录所有卡点、错误与观察（如商店推送时序、升级页与商店页的切换关系），写入 Comments。
3. 更新 architecture.md §10 冒烟清单（若顺序/步骤有调整）。

## 验收

- [ ] 清单全项通过，产出回放文件（可被 `tools/replay --summary` 解析）
- [ ] 全程无人工干预（除开始前的难度输入）
- [ ] 已知限制清单（如：升级页仅在第 N 波出现等）记录在案

## 备注

- 本票据不追求胜率；死亡即停止也视为流程通过（但需要验证死亡检测正确）。
- 若发现协议字段缺口，回开票据 05/06 补充，不在此票据内糊补。
