# ADR-0006：引擎兼容——反射访问与动态调用约定

- 状态：已接受（2026-10-06，据既有 mod 0.2.0 代码注释重建；原 ADR 文本已丢失）
- 关联：[protocol.md](../protocol.md) §8

## 背景

mod 运行在 Brotato 的 Godot 3.7 定制引擎上，需访问大量游戏内部节点与私有字段，但不能依赖编译期类型（游戏脚本不自带 `class_name`，版本间可能重命名）。

## 决策

- 所有游戏对象访问统一走动态路径：`get()` / `call()` / `has_method()` / `get_node_or_null()`；不预加载游戏脚本、不依赖 `class_name`。
- 内建类型判定用 `typeof()`（本引擎下 `is_finite()` 恒为 false，NaN 判定用自比较 `x != x`）。
- JSON 数字统一为 float；整数字段经 `engine_compat.int_arg` 收敛。
- 依赖的私有字段清单集中维护在 protocol.md §8，游戏更新后按清单冒烟。
- 场景节点使用 `%UniqueName` 或方法回退（如 `_get_shop_items_container`）双路径获取。

## 理由

- 动态访问让 mod 对游戏内部重构有一定容忍度；
- 集中清单使"更新后哪里会碎"可枚举、可测试。

## 后果

- 运行时错误替代编译期错误，需靠冒烟测试与日志兜底；
- 字段改名只能在冒烟时发现，升级适配成本仍然存在（ADR-0005 锁定版本为第一道防线）。
