# ADR-0002：决策引擎采用分层启发式，不做学习型策略

- 状态：已接受（2026-10-06）
- 关联：[strategy.md](../strategy.md)

## 背景

"高水平"需要战斗走位、资源采集、商店与升级决策。可选范式：分层启发式规则、强化/模仿学习、启发式 + 离线参数搜索。

## 决策

采用分层启发式规则引擎：反射层（30–60Hz，走位/避弹）、战术层（3–5Hz，目标/采集/血量）、经济层（事件驱动，商店/升级评分）。知识以"游戏数据导出 + 人工 Tier 标注"的形式提供；参数外置便于离线调优。

## 理由

- 已有 60Hz 结构化观测，启发式可直接利用精确状态，D0 目标不需要学习的上限；
- 单局 20–30 分钟、无并行训练环境，在线学习迭代成本不可行；
- 可解释、可复现、可回放归因，符合"稳定通关 + 复盘调优"的验收方式；
- 学习型方案保留为远期可选（需要独立环境与预算，非本目标）。

## 后果

- 策略质量依赖知识库与参数调优（票据 11–13），需要持续复盘；
- 英雄覆盖面按"通用管线 + 逐步增加 HeroProfile"扩展（票据 14）。
