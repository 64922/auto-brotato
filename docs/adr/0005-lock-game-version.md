# ADR-0005：锁定游戏版本 1.1.15.4 + 握手校验

- 状态：已接受（2026-10-06）
- 关联：[architecture.md](../architecture.md) §9、[protocol.md](../protocol.md) §2.3

## 背景

mod 大量依赖游戏内部字段（动态 `get()`/`call()`）与 UI 节点命名，游戏更新（Steam 自动更新）随时可能破坏观测/动作。可选策略：锁版本、跟随更新、多版本兼容层。

## 决策

- 锁定游戏 `1.1.15.4` 为支持版本；
- IPC 握手校验：`hello.game_version != 1.1.15.4` 或协议版本不匹配 → agent 回 `error` 拒绝会话并明确提示，mod 停止重连；
- Steam 建议"仅启动时更新"；游戏升级后先跑冒烟清单（architecture §10），通过后再放开；
- 部署工具保留可重建 zip 与配置备份，任何升级/覆盖都可回退。

## 理由

- 多版本兼容对本项目收益极低、成本极高；跟随更新则每次都要重新逆向内部字段（易碎点清单见 protocol.md §8）；
- 握手校验把"不匹配"暴露在第一秒，避免带病运行产生误导性数据；
- 单机自用场景下，版本可控。

## 后果

- 用户需接受"升级游戏 = 先跑冒烟"的操作纪律；
- 适配新版本属于独立工作项（未来票据），不在本 ADR 范围。
