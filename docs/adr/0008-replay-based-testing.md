# ADR-0008：测试以「回放录制 + 离线回归」为主，真实对局做验收

- 状态：已接受（2026-10-06）
- 关联：[strategy.md](../strategy.md) §8、[architecture.md](../architecture.md) §10

## 背景

单局真实对局 20–30 分钟，若每改一行策略都实机验证，迭代周期不可接受。系统已有低成本的结构化观测流（NDJSON 快照 + 动作），具备离线重放的物质基础。

## 决策

1. **回放录制**：agent 将对局落盘为 NDJSON（header：版本/英雄/武器/难度/时间；数据：观测、动作、ack、决策理由），存入 `recordings/`；
2. **离线回归**：`tools/replay` 以回放驱动决策引擎重放（可配置参数集），输出关键指标（生存、资源曲线、危险暴露、决策序列）；
3. **单元测试**：协议编解码、输入解析、评分函数、危险场几何；
4. **真实验收**：仅用于阶段验收（D0 10 局 ≥9 胜）与回放无法覆盖的项（UI 注入、时序、后台行为）。

## 理由

- 决策逻辑是纯函数式管线（观测 → 动作），天然可离线重放；
- 调参/回归在秒级完成，真实对局只用于最终确认；
- 回放同时是失败复盘的素材（strategy.md §8.1）。

## 后果

- 反射层需保持"可确定性重放"的接口（平滑状态随重放推进，不依赖墙钟）；
- 录制默认开启、体积可控（NDJSON 文本，可压缩归档）；`recordings/` 不入库。
