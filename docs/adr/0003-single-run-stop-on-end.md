# ADR-0003：一局制——胜利或死亡都停止并报告，不自动重试

- 状态：已接受（2026-10-06）
- 关联：[architecture.md](../architecture.md) §4.5

## 背景

系统边界需要明确："连续通关"指同一局内自动打完所有波次。若死亡后自动重开，游戏流程会回到英雄选择——而英雄/初始武器选择刻意保留人工；系统若接管该流程会破坏此边界。另有无尽/连刷等扩展形态。

## 决策

一局制：胜（第 20 波 boss 结束）或败（`alive=false` / 终局页）都停止自动控制，打印战报（结果、波次、时长、经济、构建、回放路径），回到待命状态等待用户下一次手动准备。不自动重试、不连刷、不自动切换难度。

## 理由

- 与"英雄选择保持人工"的边界一致，避免系统越权接管角色/武器/难度流程；
- 失败复盘价值大于盲目重试：战报 + 回放用于调参（ADR-0008）；
- 缩小终局自动化的范围（无需处理死亡页重开按钮等），降低耦合与风险。

## 后果

- "连续 10 局 ≥9 胜"的验收需要人工准备 10 次开局（负担可接受）；
- 若未来要连刷，需新 ADR：涉及自动重开流程与英雄选择接管。
