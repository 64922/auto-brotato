# ADR-0009：协议 v2 单客户端直接演进，不做双版本兼容

- 状态：已接受（2026-10-06）
- 关联：[protocol.md](../protocol.md) §7

## 背景

P1 需要新增菜单观测（`menu`）与菜单动作（`menu_*`）。协议存在两类演进方式：保持 v1 兼容（新消息可选、双版本协商），或直接升至 v2 并同步更新两端。

## 决策

直接演进：`PROTOCOL_VERSION` 升为 2，mod 与 agent 同仓库、同发布、同步更新；握手时双侧校验版本，不匹配即拒绝会话并提示。不保留 v1 兼容路径、不做双版本协商。

## 理由

- 单一客户端、同一维护者、部署同步，兼容层没有真实收益（AGENTS 原则：删除优于兼容）；
- 双版本会让测试矩阵与代码分支翻倍，与"锁定游戏版本"的保守策略叠加后属于不必要的复杂度；
- 版本拒绝 + 明确提示已足以避免"新旧混跑"的隐性故障。

## 后果

- 升级流程必须是"同时更新 mod 与 agent，再重启游戏"（部署工具票据 01 覆盖）；
- 若未来出现外部消费者，才需要按协议契约重新评估兼容策略。
